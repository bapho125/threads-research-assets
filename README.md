# threads-research-assets

Threads競合リサーチの投稿画像を `=IMAGE()` でスプシ表示するための**公開**再ホスト置き場。

- パス規約: `<account>/<post_id>.jpg`
- raw URL: `https://raw.githubusercontent.com/bapho125/threads-research-assets/main/<account>/<post_id>.jpg`
- 投入は note-biz の `tools/threads-img-sync.py` が自動push（手動運用なし）
- ⚠️ 公開リポジトリ（Googleが匿名取得するため必須）。機密・納品物は絶対に置かない
